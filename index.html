1

Sunday Pot

A three page recipe site for jollof rice, egusi soup and puff-puff. The ingredient lists have checkboxes that cross things out as you shop, and the pages print without the header and footer.

No JavaScript at all. Semantic HTML, flexbox, one media query, the :checked selector and a print stylesheet.

HTML, CSS

2

Keystroke

A typing speed test with 15, 30 and 60 second rounds. Letters turn white or red as you type, and it scores words per minute and accuracy, counting mistakes even after you fix them.

My first JavaScript. Events, timers, changing the page from code, and working out why the speed jumped to 400 wpm in the first second.

JavaScript, DOM

Try it Code

3

Kobo

A monthly budget tracker in naira. Add what comes in and what goes out, and it shows what is left and which categories take the most. Deleting has a five second undo.

Data that survives a refresh, one state object behind one render function, and amounts stored in kobo so the totals never pick up floating point errors.

JavaScript, localStorage, Intl

Try it Code

4

Line Dry

Tells you when to hang your washing out. It reads the hourly forecast for humidity, sun, wind and rain, scores every daylight hour, and gives each of the next three days a drying window.

Live data from a public API with fetch and async/await, code split into ES modules, and cancelling old searches with AbortController.

JavaScript, Open-Meteo API, ES modules

Try it Code

5

Tally

A command line tool that reads a bank statement exported as CSV, sorts every transaction into a category using keyword rules, and prints a summary for each month.

A second language. Python with dataclasses and Decimal, reading CSV files that every bank formats differently, and my first test suite: 23 tests.

Python, unittest

Code Runs in the terminal

6

Recall

Flashcards with spaced repetition. Cards you know come back less and less often, cards you miss come back the next day. It starts with two decks from my own course notes.

Structure. A small store, pure functions for every change to the data, a hash router and separate views, with 28 tests on Node's built in test runner.

JavaScript, node:test

Try it Code

7

Shelf

A REST API and front desk app for a small lending library. It tracks books, members and loans and enforces the rules: three books each, 14 day loans, one renewal, nothing new while a book is overdue.

The server side. Node.js and Express, business rules kept apart from the routes, a file store that cannot be left half written, and tests that send real HTTP requests.

Node.js, Express, REST

Code Runs with npm start
